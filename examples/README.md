# Desktop example

`01_polyp.jpg` is an unchanged public-domain endoscopic polyp photograph by J. Guntau, as recorded by Wikimedia Commons. Original credits include Endoskopiebilder.de and Albertinen-Krankenhaus II. Medizin.

Source: https://commons.wikimedia.org/wiki/File:Polyp.jpg

Only the filename was changed. The image has no supplied ground-truth mask and is used to demonstrate execution, not measure diagnostic accuracy. Open it with **Load test example** in the desktop application.
