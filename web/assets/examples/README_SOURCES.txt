POLYP TEST IMAGES - EndoScope AI quick trial

Five publicly available endoscopic polyp photographs downloaded on 2026-10-08.
These are web-sourced demonstration inputs, not a labeled benchmark.
No segmentation masks are supplied; do not use this pack to calculate Dice,
IoU, diagnostic accuracy, or specificity. These images are used for demonstration
and execution checks; predictions do not provide ground-truth labels.

Usage / 使用方法
Extract the ZIP, then load any JPG into EndoScope AI and run inference.
解压 ZIP 后，在 EndoScope AI 中打开任意 JPG 图片，运行检测。
All five sources describe polyps. Image 04 has a less prominent target.
These images were downloaded from Wikimedia Commons, not selected from the
project's Kvasir-SEG archive. Dataset overlap has not been formally audited.

Image bytes are unchanged from the downloaded originals; only filenames were
changed. Original on-image borders and text have been retained.
