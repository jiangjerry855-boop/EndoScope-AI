About this browser version & image sources

This app runs the same trained Compact U-Net weights as the desktop prototype, converted to ONNX. It uses aspect-preserving resizing to 160 × 160 pixels and a single-threaded WebAssembly engine. Image decoding and numerical differences can produce small changes from the desktop app. Images above 4 megapixels are resized locally before processing; exported coordinates refer to that working image.
