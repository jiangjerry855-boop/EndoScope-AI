ENDOSCOPE AI · OFFLINE CODE MAP

From image to inspectable prediction.

The browser runs the trained model on the user's device. Follow the four stages below to locate the implementation. This map describes actual code in this repository; it requires no internet connection.

01 · IMAGE

Choose and decode

web/try/app.js loads a sample or local file, checks size limits, and copies its pixels to the original-image canvas.

A selection counter prevents an older sample download from replacing the latest image.

02 · MODEL

Run the worker

inference-worker.js loads the bundled ONNX model and WASM runtime. processing.mjs letterboxes RGB data to 160 × 160 and normalizes it.

The engine returns pixel scores, then restores them to the working-image dimensions.

03 · REGIONS

Explore the threshold

findRegions() retains 8-connected regions of at least 16 pixels. The worker caches scores, so changing the threshold needs no second model run.

A higher threshold can split connected regions. Counts need not fall monotonically.

04 · EXPORT

Inspect and download

drawResult() paints the green mask and boxes. PNG and JSON buttons only export results for the current image/request and threshold.

Boxes use exclusive right/bottom coordinates; browser exports describe the locally resized working image.

Try the complete path

From the project folder, run python scripts/serve_browser.py and open localhost:8000/try/. Select a sample, run analysis, move the threshold, and inspect all three exports.

For the desktop app, install requirements.txt, run python app.py, then use Load test example.

Research and teaching only. Scores are not disease probabilities. Automated computation and state checks passed; live browser interaction, a fresh desktop installation and final learner review remain unverified. See docs/VALIDATION.md.
